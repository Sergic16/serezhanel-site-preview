# V3 hero concepts

Three isolated first-screen prototypes built from the approved `CONCEPT-V3-BRIEF.md`.

- `portrait-planes/`: portrait assembled from reactive color planes.
- `living-orbit/`: interactive service system around the portrait.
- `rhythm-collage/`: expressive editorial collage.

The existing site root remains unchanged. These prototypes intentionally stop after the hero and use simulated CTA feedback. The selected visual language must be rebuilt as a complete accessible site before any production release.

Primary review viewport: 768×1024. Supporting checks: 390×844 and desktop.

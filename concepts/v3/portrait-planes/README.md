## Variant: Портрет-конструктор

### Design stance
Тактильная персональная визитка, где образ Сергея буквально собирается из цветных плоскостей.

### Key choices
- Layout: крупная типографика слева, многослойный портрет справа.
- Typography: Golos Text, плотная и современная кириллица.
- Color: бумажный фон, синий, красный и лайм.
- Interaction: параллакс слоёв, переключение направлений, CTA-dialog.

### Trade-offs
- Strong at: личность, запоминаемость, ясная польза.
- Weak at: менее экспериментален, чем ритмический коллаж.

### Best for
Персональный сайт, который должен одновременно удивлять и вызывать доверие.

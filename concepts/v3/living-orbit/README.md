## Variant: Живой объект

### Design stance
Сайт как интерактивная система задач вокруг личности Сергея.

### Key choices
- Layout: сообщение слева, круговой объект и портрет справа.
- Typography: Onest.
- Color: лайм, бумажный белый, лиловый и голубой.
- Interaction: три орбитальные точки меняют тему и смысл экрана.

### Trade-offs
- Strong at: взаимодействие, объяснение направлений, ясный CTA.
- Weak at: менее эмоциональный и более «digital».

### Best for
Посетителей, которым важно быстро понять диапазон задач через взаимодействие.
